# Archived site files

Kept rather than deleted, per the repo rule in [CLAUDE.md](../../CLAUDE.md). Nothing here is
built or served. Do not edit these files expecting a change to appear on the site.

| File | Archived | What replaced it |
|---|---|---|
| `map-engine-v1.js` | 2026-10-02 | The first map engine: fourteen stages in one row, which was legible at thirty skills and a strip of unreadable boxes at fifty-three. Replaced by the snake layout in [`lib/map-engine.js`](../lib/map-engine.js): two bands, lanes for crowded stages, zoom to a stage or a tile, and a panel that always says where you are. |
| `skills-browser.tsx` | 2026-10-02 | The card grid that fronted `/skills`. Replaced by [`components/skills-library.tsx`](../components/skills-library.tsx), a library with folders and a drawer, and [`components/skill-detail.tsx`](../components/skill-detail.tsx), which both the drawer and `/skills/[id]` render. |
| `single-page-map.html` | 2026-07-26 | The self-contained single-page map, generated by the old `site/build.mjs`. Superseded when the site became a Next.js app: its SVG drawing code lived on unchanged in `map-engine-v1.js` (above) until 2026-10-02, its styles in [`app/map/map.css`](../app/map/map.css), and its About copy in [`map.config.json`](../map.config.json) under `about`. |
