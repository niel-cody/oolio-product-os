# Slack message

Six to ten lines. For whoever lives in Slack rather than Teams. Sent as a **draft** through the Slack connector after approval, so the last click stays with a person.

## Structure

```
*<Product> release, <D Month>: <the claim>*

<One line of why.>

• <Theme 1 as an outcome, one line>
• <Theme 2, one line>
• <Theme 3, one line>                 (three bullets at most)

<One line on what is not covered or not shipped, if it matters to this audience.>

Next: <D Month> <what for>, then <D Month> <what for>. Dates subject to change.
Full notes: <customer page URL>
```

## Rules

- Slack mrkdwn: `*bold*`, `•` bullets, no headings.
- No Jira keys. If a reader needs them, the Confluence page is one click away.
- Not a trimmed Teams message. Written fresh from the record, in the shortest form the facts allow.
- Channel: ask on the first run for a product and record it in `product-map.md`.
